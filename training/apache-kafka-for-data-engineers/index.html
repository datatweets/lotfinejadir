دوره‌ی پردازش داده‌ی جریانی با Kafka

Apache Kafka for Data Engineers

آموزش عملی Apache Kafka برای پردازش جریان رویدادها در محیط محلی؛ از نصب و تولید و مصرف پیام تا Schema Registry، Kafka Connect و پردازش جریانی. این دوره به زبان فارسی و به‌صورت حضوری یا آنلاین برای تیم‌های سازمانی برگزار می‌شود.

آنچه شرکت‌کنندگان می‌آموزند

  • نصب و اجرای یک خوشه‌ی واقعی Apache Kafka 4.0 با سه Broker در حالت KRaft
  • تولید و مصرف رویدادهای واقعی با گروه‌های مصرف‌کننده و تحویل قابل‌اعتماد
  • اعمال قرارداد داده با Schema Registry و انتقال داده با Kafka Connect
  • پردازش بلادرنگ جریان‌ها با Faust و Spark Structured Streaming

کار عملی: یک خوشه‌ی واقعی Kafka با سه Broker برای جریان رویدادهای سفر شرکت CityFlow

پیش‌نیازها

  • نیازی به تجربه‌ی قبلی Kafka نیست؛ دوره از اولین پیام شروع می‌شود
  • آشنایی مقدماتی با پایتون: خواندن و اجرای اسکریپت و مدیریت وابستگی‌های پایه
  • آشنایی با خط فرمان
  • Docker Desktop (نصب آن در بخش ۱ آموزش داده می‌شود)

دوره‌های پیشنهادی برای تقویت پیش‌نیاز:

  • پایتون برای تحلیل داده
  • SQL و پایگاه داده
