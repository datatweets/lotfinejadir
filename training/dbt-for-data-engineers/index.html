دوره‌ی مدل‌سازی داده با dbt

dbt for Data Engineers

آموزش مهندسی تحلیل با dbt در محیط محلی؛ شامل نصب dbt Core، راه‌اندازی انبار داده‌ی Postgres در Docker و تبدیل داده از لایه‌ی Staging تا آزمون و ساخت Mart. این دوره به زبان فارسی و به‌صورت حضوری یا آنلاین برای تیم‌های سازمانی برگزار می‌شود.

آنچه شرکت‌کنندگان می‌آموزند

  • نصب و اجرای dbt Core روی یک انبار داده‌ی واقعی Postgres در Docker
  • ساخت مدل‌های Staging، میانی و Mart که با ref() و source() به هم پیوند خورده‌اند
  • آزمون و مستندسازی داده با آزمون‌های عمومی، اختصاصی و واحد dbt
  • ساخت مدل‌های افزایشی و Snapshot و زمان‌بندی dbt با Airflow

کار عملی: یک DAG کامل، آزموده و مستند در dbt برای تبدیل داده‌های سفر CityFlow روی Postgres و DuckDB، با استقرار و زمان‌بندی در Airflow

پیش‌نیازها

  • نیازی به تجربه‌ی قبلی dbt نیست؛ دوره از اولین مدل شروع می‌شود
  • تسلط بر SQL (SELECT، JOIN و GROUP BY)
  • آشنایی با خط فرمان
  • Docker Desktop (نصب آن در بخش ۱ آموزش داده می‌شود)

دوره‌های پیشنهادی برای تقویت پیش‌نیاز:

  • SQL و پایگاه داده
  • کنترل نسخه با Git و GitHub
