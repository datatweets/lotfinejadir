دوره‌ی SQL و پایگاه داده

SQL & Databases

آموزش SQL از نخستین پرس‌وجو تا کار با پایگاه‌های داده‌ی عملیاتی؛ شامل Join، توابع پنجره‌ای، PostgreSQL و SQLAlchemy، همراه با تمرین روی داده‌های واقعی. این دوره به زبان فارسی و به‌صورت حضوری یا آنلاین برای تیم‌های سازمانی برگزار می‌شود.

آنچه شرکت‌کنندگان می‌آموزند

  • نوشتن کوئری‌های SQL برای انتخاب، فیلتر، مرتب‌سازی و تجمیع داده در یک پایگاه داده‌ی واقعی
  • ترکیب جدول‌ها با Join و پاسخ به پرسش‌های پیچیده‌تر با زیرکوئری، CTE و View
  • رتبه‌بندی، مقایسه و محاسبه روی سطرها با توابع پنجره‌ای، بدون خروج از SQL
  • طراحی، بارگذاری و مدیریت PostgreSQL و بهینه‌سازی کوئری‌های کند با ایندکس
  • اجرای کوئری روی پایگاه داده از درون پایتون، به‌صورت مستقیم و با SQLAlchemy

سرفصل دوره

سرفصل شامل ۱۰ بخش و ۵۳ درس است. برنامه‌ی پیشنهادی ۴ روز آموزشی (۳۲ ساعت) است؛ مدت نهایی، تمرین‌ها و شیوه‌ی ارزیابی بر اساس سطح و نیاز تیم پیش از برگزاری تعیین می‌شوند.

  1. ۱

    شروع کار با SQL

    ۷ درس
    • آشنایی با پایگاه داده و Schema
    • ستون‌ها، انواع داده و توابع
    • فیلتر سطرها بر اساس مقادیر عددی
    • فیلتر بر اساس متن و دسته‌بندی
    • مرتب‌سازی و محدودکردن نتایج
    • منطق شرطی با CASE و سبک نوشتن تمیز
    • پروژه‌ی راهنمادار: تحلیل کمپین‌های Kickstarter
  2. ۲

    خلاصه‌سازی داده با SQL

    ۴ درس
    • توابع تجمیعی: COUNT، SUM، AVG و سایر توابع
    • ساخت آماره‌های خلاصه
    • گروه‌بندی داده با GROUP BY
    • گروه‌بندی بر اساس چند ستون و فیلتر گروه‌ها
  3. ۳

    ترکیب جدول‌ها با Join

    ۴ درس
    • آشنایی با Join
    • Join همراه با فیلتر، گروه‌بندی و مرتب‌سازی
    • Self Join، Outer Join و Cross Join
    • ترکیب نتایج با عملگرهای مجموعه‌ای
  4. ۴

    زیرکوئری، CTE و View

    ۶ درس
    • زیرکوئری‌های تک‌مقداری
    • زیرکوئری‌های چندسطری و چندستونی
    • زیرکوئری‌های تودرتو و وابسته
    • عبارات جدولی مشترک (CTE)
    • ساخت و استفاده از View
    • پروژه‌ی راهنمادار: تحلیل مشتریان و محصولات
  5. ۵

    توابع پنجره‌ای

    ۷ درس
    • آشنایی با توابع پنجره‌ای
    • قاب پنجره: ROWS و RANGE
    • توابع تجمیعی پنجره‌ای
    • توابع رتبه‌بندی: ROW_NUMBER، RANK و NTILE
    • توابع جابه‌جایی: LAG، LEAD و FIRST_VALUE
    • توابع توزیع و صدک
    • پروژه‌ی راهنمادار: تحلیل فروش شرکت Northwind Traders
  6. ۶

    کوئری‌نویسی روی پایگاه داده از پایتون

    ۲ درس
    • اجرای کوئری SQL با sqlite3
    • از نتیجه‌ی SQL تا DataFrame در pandas
  7. ۷

    PostgreSQL برای مهندسان داده

    ۷ درس
    • آشنایی با PostgreSQL
    • طراحی جدول و انتخاب نوع داده
    • Prepared Statement و جلوگیری از حمله‌ی SQL Injection
    • بارگذاری و کپی داده
    • مدیریت کاربران و پایگاه‌های داده
    • پروژه: نصب PostgreSQL روی سیستم محلی
    • پروژه‌ی راهنمادار: ساخت پایگاه داده‌ی گزارش‌های جرم
  8. ۸

    بهینه‌سازی PostgreSQL

    ۵ درس
    • آشنایی با ساختار درونی PostgreSQL
    • خواندن طرح اجرای کوئری با EXPLAIN
    • افزایش سرعت کوئری‌ها با ایندکس
    • راهبردهای پیشرفته‌ی ایندکس‌گذاری
    • Vacuum، تراکنش‌ها و اصول ACID
  9. ۹

    ابزارهای پایگاه داده در محیط عملیاتی

    ۳ درس
    • انبار داده‌ی ابری با Snowflake
    • آشنایی با پایگاه‌های داده‌ی NoSQL
    • کار عملی با MongoDB
  10. ۱۰

    SQLAlchemy در پایتون

    ۸ درس
    • اتصال با Engine و Metadata
    • تعریف جدول و درج داده
    • کوئری‌نویسی با select() و where()
    • Join و Self-Join
    • به‌روزرسانی، حذف و تراکنش‌ها
    • ORM: مدل‌های اعلانی و Session
    • صفحه‌بندی، عملیات انبوه و کارایی
    • پروژه‌ی راهنمادار: تحلیل داده‌های سرشماری آمریکا
