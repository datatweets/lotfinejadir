دوره‌ی Docker و Kubernetes برای مهندسان داده

Docker & Kubernetes for Data Engineering

آموزش استقرار و مدیریت جریان داده با Docker و Kubernetes؛ شامل Image، Dockerfile، Compose و خوشه‌ی محلی Kind، با تمرین‌های اجرایی روی رایانه‌ی شخصی. این دوره به زبان فارسی و به‌صورت حضوری یا آنلاین برای تیم‌های سازمانی برگزار می‌شود.
