دوره‌ی کنترل نسخه با Git و GitHub

Version Control with Git & GitHub

آموزش Git و GitHub از مبانی تا همکاری تیمی؛ شامل ثبت تغییرها، ایجاد و ادغام شاخه‌ها، کار با Pull Request و به‌کارگیری روندهای کاری رایج در تیم‌های نرم‌افزاری. این دوره به زبان فارسی و به‌صورت حضوری یا آنلاین برای تیم‌های سازمانی برگزار می‌شود.
