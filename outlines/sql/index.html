  • نوشتن کوئری‌های SQL برای انتخاب، فیلتر، مرتب‌سازی و تجمیع داده در یک پایگاه داده‌ی واقعی
  • ترکیب جدول‌ها با Join و پاسخ به پرسش‌های پیچیده‌تر با زیرکوئری، CTE و View
  • رتبه‌بندی، مقایسه و محاسبه روی سطرها با توابع پنجره‌ای، بدون خروج از SQL
  • طراحی، بارگذاری و مدیریت PostgreSQL و بهینه‌سازی کوئری‌های کند با ایندکس
  • اجرای کوئری روی پایگاه داده از درون پایتون، به‌صورت مستقیم و با SQLAlchemy

پیش‌نیازها

  • نیازی به آشنایی قبلی با SQL نیست؛ دوره از اولین کوئری شروع می‌شود
