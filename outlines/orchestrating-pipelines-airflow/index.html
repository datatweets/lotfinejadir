مدیریت و زمان‌بندی جریان‌های داده با Airflow

Orchestrating Data Pipelines with Airflow

آموزش مدیریت و زمان‌بندی جریان‌های داده با Apache Airflow؛ شامل DAG، Operator، Sensor، Hook، آزمون و پایش، همراه با پروژه‌ای که Airflow، PySpark و Kubernetes را یکپارچه می‌کند.

آنچه شرکت‌کنندگان می‌آموزند

  • طراحی و نوشتن DAG در Airflow با TaskFlow API و Operatorهای کلاسیک
  • انتظار برای سامانه‌های بیرونی و اتصال به آن‌ها با Sensor، Hook و Connection
  • آزمون، ثبت رویداد، پایش و هشدار در صورت شکست DAG
  • اجرای یک پردازش PySpark روی Kubernetes از درون DAG در Airflow

پیش‌نیازها

  • تسلط بر پایتون: خواندن و اجرای اسکریپت و مدیریت وابستگی‌های پایه
  • آشنایی با خط فرمان
  • Docker Desktop و برای پروژه‌ی پایانی، یک خوشه‌ی محلی Kind
